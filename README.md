# Cloth Simulation

Unity로 만든 천 시뮬레이션입니다.

## 소개

중력이나 바람을 바꿔 가면서 천이 어떻게 움직이는지 보는 프로그램입니다.
Windows에서 돌아갑니다.

## 기능

- 천 시뮬레이션
- 중력, 바람 조절
- 오브젝트 추가/삭제
- 카메라 회전, 확대/축소

## 실행 방법

아래 파일 중 하나를 받아서 실행합니다.

- [ClothSimLab-Installer.exe](https://github.com/dlwotjdlwotj/Cloth-Simulation/releases/latest/download/ClothSimLab-Installer.exe): 설치 마법사입니다. 안내에 따라 다음을 누르면 프로그램이 설치됩니다.
- [ClothSimLab-Portable.exe](https://github.com/dlwotjdlwotj/Cloth-Simulation/releases/latest/download/ClothSimLab-Portable.exe): 실행하면 압축이 자동으로 풀리고 프로그램이 실행됩니다.
- [ClothSimLab-Windows.zip](https://github.com/dlwotjdlwotj/Cloth-Simulation/releases/latest/download/ClothSimLab-Windows.zip): 원하는 폴더에 압축을 푼 다음 `ClothSimLab.exe`를 실행합니다.

## 사용 방법

1. 마우스 오른쪽을 누른 채로 끌면 화면이 돌아갑니다.
2. 휠로 확대하거나 줄이면 됩니다.
3. Tab을 누르면 UI가 사라졌다가 다시 나옵니다.
4. 왼쪽에서 오브젝트를 넣거나 지울 수 있습니다.
5. 오른쪽에서 중력이랑 바람을 바꿉니다.
6. 끌 때는 종료를 누르면 됩니다.

## 기술 스택

- Unity 2022.3
