# Cloth Simulation

Windows에서 바로 실행할 수 있는 천 시뮬레이션입니다.

[![Windows exe 받기](https://img.shields.io/badge/Download-Windows%20exe-0E7A0D?style=for-the-badge&logo=windows&logoColor=white)](https://github.com/dlwotjdlwotj/Cloth-Simulation/releases/latest/download/ClothSimLab-Setup.exe)

`ClothSimLab-Setup.exe`를 받아 실행하세요. 설치 후 바로 실행됩니다.

## 조작

- 마우스 오른쪽 드래그: 카메라 회전
- 스크롤: 확대/축소
- Tab: UI 숨기기/보이기
- 왼쪽 패널: 오브젝트 추가/삭제
- 오른쪽 패널: 중력, 바람
- 종료: 프로그램 닫기
